# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.4.0] - 2026-09-10

### Added

- Optional client override stylesheet support for generated sites.
- A featured-release Spotify player on the homepage.
- A Copilot setup workflow for cloud agent sessions.

### Changed

- Documented how client builds can provide `assets/css/override.css`.

## [0.3.1] - 2026-08-15

### Added

- YouTube social links.

## [0.3.0] - 2026-08-03

### Changed

- Streaming links can now be built from service-specific identifiers with URL overrides.

### Fixed

- Added the missing tests for streaming URL override support.

## [0.2.0] - 2026-08-03

### Added

- YouTube support for songs.

## [0.1.1] - 2026-07-31

### Added

- Automated tests, CI workflow, and site data fixtures.

### Changed

- Updated CPAN dependencies.

## [0.1.0] - 2026-07-30

### Added

- Initial release of the artist site engine.
- Docker image build and publish support using `VERSION.x.x.x` tags.
